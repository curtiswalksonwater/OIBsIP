# Personal Portfolio Website

## Project Overview
A responsive personal portfolio website showcasing skills, projects, and contact information. Built for the Oasis Infobyte Web Development Internship (Level 1, Task 2).

## Features
- Profile/hero section with name, role, and avatar
- About Me section
- Skills section with visual grid
- Projects section with 2 project cards
- Contact section with email and social links
- Smooth scroll navigation
- Fully responsive design

## Tech Stack
- HTML5
- CSS3
