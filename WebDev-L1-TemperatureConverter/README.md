# Temperature Converter

## Project Overview
An interactive web tool that converts temperature values between Celsius, Fahrenheit, and Kelvin with real-time input validation. Built for the Oasis Infobyte Web Development Internship (Level 1, Task 3).

## Features
- Numeric input field with validation
- Unit selector dropdown (Celsius, Fahrenheit, Kelvin)
- Auto-conversion showing all three output units
- Convert button triggers calculation
- Edge case handling for absolute zero violations
- Clean, centered UI layout

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
